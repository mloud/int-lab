# Git Workflow a pravidla pro Commits/Pushes

- **Nikdy necommituj přímo do větve `main` (nebo `master`)**, pokud to uživatel explicitně nenařídí.
- **Vždy se zeptej uživatele**, než spustíš příkazy `git commit` nebo `git push`.
- Při dotazování nabídni možnost vytvořit novou větev nebo použít existující větev a vyčkej na rozhodnutí uživatele, do jaké větve se má kód uložit.
- Automatické vytváření commitů bez uživatelského souhlasu je přísně zakázáno.
